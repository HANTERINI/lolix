# 🔥 Meme Craft Pro (LOLIX Meme Generator)

Ультимативный онлайн-генератор мемов на базе HTML5 Canvas и Vercel!

![Vercel](https://img.shields.io/badge/Vercel-Deployed-black?logo=vercel)
![License](https://img.shields.io/badge/License-MIT-blue)

## 🚀 Возможности
- 🎨 **60+ Популярных шаблонов** мемов с поддержкой Imgflip API.
- 🔤 **Уникальный текст на каждом шаблоне** (автоматический перенос строк, выравнивание, обводка, тени).
- 🖼️ **Векторные фолбек-шаблоны**: Работает 100% стабильно даже при блокировках сети/CORS.
- 🕶️ **Библиотека стикеров и эмодзи** (Thug Life очки, огонь, клоун и др.).
- 🔥 **Эффект Deep Fry (Пережаренный мем)** и управление контрастом, яркостью, сепией.
- ✏️ **Режим рисования (Кисть)** поверх изображения.
- 📥 **Скачивание в PNG** и **Прямое копирование в буфер обмена**.
- 💾 **Моя галерея**: Сохранение созданных мемов в `localStorage`.

## 🛠️ Деплой на Vercel

### Вариант 1: Импорт репозитория GitHub
1. Перейдите на [Vercel Dashboard](https://vercel.com/new).
2. Выберите репозиторий `HANTERINI/lolix`.
3. Нажмите **Deploy** — готово!

### Вариант 2: Через Vercel CLI
```bash
npx vercel --prod
```
